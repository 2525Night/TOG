# TOG (Lane Pulse)

Android-first endless runner built with **Godot 4 + C#**.

## Hook

The **safe lane** shifts on a pulse beat — stay inside it or die. Score = pulses survived.

## MVP scope

- 3-lane one-thumb controls (swipe / tap)
- Pulse timer + safe-lane highlight
- Local high streak save
- Title → Play → Game Over flow
- Mock ads + Remove Ads IAP interfaces (real AdMob/Play Billing later)

## Stack

- Godot 4.5+
- C# (.NET)
- Target: Android portrait
