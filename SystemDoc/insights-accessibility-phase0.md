# נגישות מסקנות — שלב 0 (לפני רועי / LLM)

**סטטוס:** בוצע (ספט׳ 2026)  
**מטרה:** מסקנות כספיות בעברית פשוטה, בגובה העיניים — **בלי** צ׳אט, **בלי** LLM, **בלי** שירות AI חדש.

## מה נעשה בשלב 0

1. **מסקנה קודם, מספר אחר כך** על `/app` (תמונת מצב) ו־`/app/reports` (מאזן).
2. חוזה קל ל־attention מ־`IntelligenceService.analyze()`:
   - `conclusionHe` — מה להבין קודם
   - `meaningHe` — מה זה אומר למשתמש לא־פיננסי
   - `moneyLineHe` — שורת כסף מ־**MonthFacts** בלבד
   - `ctaHe` + `href` — פעולה אחת
   - aliases: `titleHe` / `bodyHe` (לתאימות התראות / לקוחות ישנים)
3. העתקה רגועה (שפת מוצר): זמין בפועל, שמור לתשלומים, קבועים, גמיש, נותר, אשראי והלוואות.
4. חודשים דלים / חלקיים נשארים שקטים (`signalsReliable` + `dataGaps`) — בלי אזהרות מפחידות.
5. `healthScore` מחושב ב־API אך **לא מוצג** ב־UI עד שיוסבר.
6. אות חדש אחד מבוסס MonthFacts: **גמיש מעל תקרה** (`flexible-over-cap`).
