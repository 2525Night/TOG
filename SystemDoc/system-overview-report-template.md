# 4. מה החזון?

_למילוי: פסקה + תרשים מסלול. החזון חייב להיות שאפתני אך תואם גבולות אתיים/רגולטוריים._

**מסלול החזון (קונספט):**

```
יציאה ממשבר → התייצבות → ביטחון כלכלי → צמיחה → עצמאות כלכלית
(RECOVERY)   (STABILIZATION) (SECURITY)  (GROWTH) (INDEPENDENCE)
```

**דוגמה — ניסוח חזון:**  
MoneyTail אינה מיועדת רק למי שכבר «בסדר». היא צריכה לקבל משתמש בנקודת **חובות + מינוס + משכורת**, לתת שליטה, ואז ללוות אותו עד ביטחון, צבירת הון, ובטווח הארוך — מדדי עצמאות (למשל כיסוי הוצאות מהכנסה שאינה משכורת). ההצלחה נמדדת גם במרחק מנקודת הפתיחה האישית.

_סטטוס חזון מול מימוש:_ ☐ רוב השלבים במוצר · ☐ שלבי ליבה בלבד · ☐ קונספט מתועד  

**דוגמה סטטוס:** שלבי Recovery–Security נתמכים חלקית במוצר (תזרים, אשראי/הלוואות, רזרבה); Growth/Independence ומרכז הוצאה לפועל — בעיקר קונספט.

_למילוי: איך הרעיונים מתחברים בממשק ובתודעת המשתמש._

```
תמונת מצב (איפה אני?) 
    ← MonthFacts + נזילות
תנועות (מה קרה?)
    ← רישום, קבועים, ייבוא
מאזן (סיפור החודש)
    ← נרטיב / דוחות
אשראי והלוואות (מה פתוח / מה יורד?)
```

קנייה בכרטיס = הוצאה (לא תנועת עו״ש); סילוק = עו״ש בלי ספירת הוצאה כפולה; תשלום הלוואה = הוצאה + הורדת יתרת הלוואה. מינוס עו״ש נגזר מנזילות — לא מכרטיס.
