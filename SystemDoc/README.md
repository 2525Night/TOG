# SystemDoc

תיקייה זו משמשת לקבצים חשובים בעת בניית המערכת.

כאן נשמרים מסמכי קונספט, החלטות מוצר, עקרונות ליבה ומסמכי עבודה שמלווים את הפיתוח — לא קוד מימוש.

המטרה: מקור אחד ברור למה שהמערכת אמורה להשיג ולמה היא בנויה כך.

## מסמכים

- **`system-overview-report-template.md`** — תבנית דוח מערכת כללי (למילוי): זהות, קהל, מטרה, חזון, מנגנון ערך, IN/OUT, מדדים, סיכונים, כרטיס בשלות + דוגמאות MoneyTail.
- **`concept-path-debt-to-independence.md`** — טיוטת קונספט: מסלול מחובות לעצמאות כלכלית (שלבים, מרכזי חובות והוצאה לפועל, חזון).
- **`product-language-credit-loans.md`** — שפת מוצר למשתמש: אשראי והלוואות (בלי תווית «חוב» לוחצת), נזילות, אזורים בדף.
- **`stage-emergency-reserve.md`** — שלב מערכת: רזרבה להפתעות (כרית) — הגדרה מלאה + תוכנית עבודה.
- **`stage-credit-installments.md`** — שלב מערכת: אשראי — תשלומים / רטרו / הוראת קבע (גל 1) + צ׳ק־ליסט גימור.
- **`ux-friendliness-accessibility-audit.md`** — ביקורת ידידותיות + נגישות (כולל CRUD בכל דף), ספט׳ 2026.
- **`insights-accessibility-phase0.md`** — שלב 0: מסקנות בעברית פשוטה (לפני רועי/LLM) — חוזה insight + מה נדחה במפורש.
- **`onboarding-first-details-review.md`** — חוות דעת: פרטים ראשונים בהרשמה ובהקמה מול מסלול משבר→שליטה (ספט׳ 2026) + **ביקורת חוזרת אחרי מימוש** שלב כרטיסים אופציונלי (2026-09-08).
