| # | רמה | שאלה |
|---|-----|------|
| 1.1 | קלה | כשאתם נכנסים למסך הבית, מה הדבר **הראשון** שאתם שמים לב אליו — ולמה לדעתכם הוא בולט? |
| 1.2 | קלה–בינונית | האם אתם מרגישים שיש על המסך «דבר אחד חשוב» ברור, או שכמה דברים מתחרים על תשומת הלב באותו זמן? תארו במילים שלכם. |

| 1.4 | בינונית–קשה | אם הייתם צריכים להסביר לחבר שאינו מכיר את האפליקציה «מה הכי חשוב במסך הזה», מה הייתם אומרים — ומה עלול לבלבל אותו? |
| 1.5 | קשה | אחרי שנה של שימוש: האם יש מסכים שבהם אתם עדיין «מחפשים עם העיניים» לפני שאתם מבינים מה קורה — ואם כן, מה בדיוק גורם לזה? |

| # | רמה | שאלה |
|---|-----|------|
| 2.1 | קלה | איך אתם בדרך כלל עוברים בין חלקי האפליקציה (תפריט, לשוניות, כפתורים)? מה מרגיש הכי טבעי עבורכם? |
| 2.2 | קלה–בינונית | האם קרה שחיפשתם משהו (למשל הלוואה, כרטיס, דוח) ולא מצאתם מיד — איך הרגשתם ומה עשיתם אחר כך? |
| 2.3 | בינונית | כשאתם נמצאים במסך פנימי (פרטי הלוואה / כרטיס / יעד), עד כמה ברור לכם איך לחזור «הביתה» בלי ללחוץ באקראי? |
| 2.4 | בינונית–קשה | האם שמות המסכים והכפתורים מתאימים למה שאתם מצפים למצוא שם — או שיש מקומות שבהם השם «מבטיח משהו אחר» ממה שמופיע? |
| 2.5 | קשה | אחרי שימוש ארוך: האם יש מסלול באפליקציה שאתם **עדיין נמנעים ממנו** כי קשה להתמצא בו — ומה הייתם משנים כדי שירגיש פשוט יותר? |

| 3.2 | קלה–בינונית | יש מקומות שבהם הטקסט מרגיש צפוף מדי, ארוך מדי, או «נעלם» ברקע? תארו איפה ומה מפריע. |
| 3.3 | בינונית | כשמופיעים מונחים כמו «זמין בפועל», «שמור לתשלומים» או שמות שלבים במסע — האם הניסוח והעיצוב עוזרים להבין, או שצריך לנחש? |

| 3.5 | קשה | אם הייתם יכולים לשנות רק דבר אחד שקשור לטקסט ולקריאות בכל האפליקציה — מה זה היה, ולמה דווקא זה? |

| 4.2 | קלה–בינונית | האם קל להבחין בין מידע «טוב / בסדר» לבין מידע שדורש תשומת לב, רק לפי הצבעים והעיצוב — בלי לקרוא הכל? |

## נספח למנחה / חוקר UX

### סדר מומלץ בראיון
1. קטגוריות 1–2 (בהירות + ניווט)  
2. קטגוריות 3–5 (קריאה, צבע, עומס)  
3. קטגוריות 6–7 (נוחות יומיומית + משוב)  
4. קטגוריה 8 (רגש ואמון — לסיום, כשיש פתיחות)

### משך מומלץ
- מלא (40 שאלות): ~75–90 דקות — עדיף לפצל לשני מפגשים  
- מקוצר: לבחור שאלות קלה + קשה מכל קטגוריה (16 שאלות, ~35–45 דקות)

### תיוג תשובות (לניתוח)
- `בהירות` · `ניווט` · `קריאות` · `צבע/ניגודיות` · `עומס` · `מגע/מובייל` · `משוב/ביטחון` · `רגש/אמון`
- סימון נוסף: `כאב` / `ניצחון` / `רעיון לשיפור`

### הערת מוצר
השאלון ממוקד **עיצוב ונוחות**, לא בדיקת לוגיקה פיננסית. לכיסוי תוכן מוצר (יתרה מול זמין, Roey, רזרבה וכו') יש להיעזר בשאלון המוצרי הקיים / דוח האמולטור ב־`ux-questionnaire-emulator-report.md`.
